# AzamPay Payment Integration Guide

This guide describes how to integrate your main web application with the Payment Processor. The processor acts as a proxy for **AzamPay**, simplifying the integration process to a few unified API calls.

---

## 2. Initiating a Payment Request

You send a JSON payload to the processor to start a payment.

### API Endpoint

```http
POST https://ludicrous-unsorted-balance.ngrok-free.dev/api/v1/payments/initiate
Content-Type: application/json
Accept: application/json
```

### Request Parameters

| Field | Type | Required | Description |
|---|---|---|---|
| `amount` | numeric | Yes | The payment amount in TZS (minimum: 1). |
| `phone` | string | Yes | The customer's mobile number (e.g. `0712345678`, `255712345678`). |
| `external_reference` | string | Yes | Your unique transaction reference (e.g. Invoice ID, Order ID). |

### Request Example (JSON)

```json
{
  "amount": 15000,
  "phone": "0712345678",
  "external_reference": "INV-2026-881"
}
```

### Response Format

#### AzamPay Mobile Push Initiation (Successful)
**AzamPay**, triggers a direct USSD push prompt on the customer's mobile phone asking for their wallet PIN.

```json
{
  "success": true,
  "external_reference": "INV-2026-881",
  "gateway_reference": "AZ-89109312",
  "payment_url": null,
  "message": "Payment initiated successfully."
}
```

*Action required in Web App:* Render a waiting screen instructing the customer to check their phone and enter their mobile money wallet PIN.

#### Initiation Failed
If the request is rejected by the gateway provider or fails to authenticate:

```json
{
  "success": false,
  "external_reference": "INV-2026-881",
  "message": "Failed to generate AzamPay token: Invalid credentials."
}
```

## 3. Receiving Payment Notifications (Webhooks)

When the customer completes the payment, the gateway notifies the processor, which processes the webhook, updates its SQLite database, and forwards the normalized callback to your web app's configured webhook endpoint.

### Configure Your Callback URL
In the processor's Control Panel GUI, set **Web App Callback URL** to your web application's endpoint:
`https://yourwebapp.com/api/v1/payments/callback`

### Webhook Payload Format

When the customer completes the payment, your webhook endpoint will receive a **standardized payload**:

```json
{
  "external_reference": "INV-2026-881",
  "gateway": "azampay",
  "gateway_reference": "AZ-89109312",
  "amount": 15000.00,
  "status": "success",
  "phone": "255712345678",
  "message": "Payment completed successfully",
  "timestamp": "2026-07-21T17:45:00+03:00"
}
```

### Payload Fields

| Field | Type | Description |
|---|---|---|
| `external_reference` | string | Your original transaction ID sent during initiation. |
| `gateway` | string | The driver used (`azampay`). |
| `gateway_reference` | string | The transaction ID generated by the gateway provider. |
| `amount` | float | The amount paid. |
| `status` | string | **`success`** or **`failed`**. |
| `phone` | string | Customer's phone number in normalized `255xxxxxxxxx` format. |
| `message` | string | Status description or details. |
| `timestamp` | string | ISO-8601 formatted event timestamp. |

> **IMPORTANT**: Your webhook endpoint must return an **HTTP 200 OK** response to acknowledge that the callback was received.

## 4. Querying/Fetching Status (Polling)

If you need to fetch or verify the current status of a payment directly (e.g. if the webhook is delayed or if you want to poll status from the frontend), you can query the status endpoint.

### API Endpoint

```http
GET https://ludicrous-unsorted-balance.ngrok-free.dev/api/v1/payments/status/{external_reference}
Accept: application/json
```

### Response Format

#### 1. Payment Succeeded

```json
{
  "success": true,
  "external_reference": "INV-2026-881",
  "status": "success",
  "amount": 15000.00,
  "gateway": "azampay",
  "gateway_reference": "AZ-89109312",
  "message": "Payment completed successfully",
  "created_at": "2026-07-21T17:43:00+03:00",
  "updated_at": "2026-07-21T17:45:00+03:00"
}
```

#### 2. Payment Pending (Awaiting Customer Action)

```json
{
  "success": true,
  "external_reference": "INV-2026-881",
  "status": "pending",
  "amount": 15000.00,
  "gateway": "azampay",
  "gateway_reference": "AZ-89109312",
  "message": "Payment is pending",
  "created_at": "2026-07-21T17:43:00+03:00",
  "updated_at": "2026-07-21T17:43:00+03:00"
}
```

#### 3. Payment Failed

```json
{
  "success": true,
  "external_reference": "INV-2026-881",
  "status": "failed",
  "amount": 15000.00,
  "gateway": "azampay",
  "gateway_reference": "AZ-89109312",
  "message": "Payment failed",
  "created_at": "2026-07-21T17:43:00+03:00",
  "updated_at": "2026-07-21T17:44:12+03:00"
}
```

#### 4. Reference Not Found

```json
{
  "success": false,
  "message": "Payment log not found"
}
```

## 5. Integration Code Snippets

### Laravel (PHP)

```php
use Illuminate\Support\Facades\Http;

class PaymentController extends Controller
{
    private string $processorUrl = 'https://ludicrous-unsorted-balance.ngrok-free.dev';

    /**
     * Initiate checkout.
     */
    public function checkout(Order $order)
    {
        $response = Http::post($this->processorUrl . '/api/v1/payments/initiate', [
            'amount' => $order->total_amount,
            'phone' => $order->customer_phone,
            'external_reference' => $order->id,
            'name' => $order->customer_name,
            'email' => $order->customer_email,
            'gateway' => 'azampay'
        ]);

        $result = $response->json();

        if ($result['success']) {
            if (!empty($result['payment_url'])) {
                // Selcom: Redirect
                return redirect($result['payment_url']);
            }
            
            // AzamPay: Instruct customer to check their phone
            return view('checkout.waiting', ['order' => $order]);
        }

        return back()->with('error', $result['message']);
    }

    /**
     * Poll transaction status from Webapp frontend.
     */
    public function checkStatus(string $orderId)
    {
        $response = Http::get($this->processorUrl . "/api/v1/payments/status/{$orderId}");
        return response()->json($response->json());
    }
}
```

### Express (Node.js)

```javascript
const axios = require('axios');
const PROCESSOR_URL = 'https://ludicrous-unsorted-balance.ngrok-free.dev';

// 1. Initiate Payment
async function startPayment(amount, phone, reference) {
  try {
    const res = await axios.post(`${PROCESSOR_URL}/api/v1/payments/initiate`, {
      amount,
      phone,
      external_reference: reference
    });
    return res.data;
  } catch (error) {
    return { success: false, message: error.response?.data?.message || error.message };
  }
}

// 2. Poll Status
async function getPaymentStatus(reference) {
  try {
    const res = await axios.get(`${PROCESSOR_URL}/api/v1/payments/status/${reference}`);
    return res.data;
  } catch (error) {
    return { success: false, message: 'Status check failed' };
  }
}
```
